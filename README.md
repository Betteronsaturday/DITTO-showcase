# DITTO

Nutrition and fitness coach for iOS and Android. People log meals, workouts, and goals, and talk to an AI coach that knows their profile. Health data stays on their account.

**Case study:** [Figma prototype](https://www.figma.com/proto/LVpE43YECdEcfdrBsepa8p/DITTO?page-id=2735%3A11609&node-id=2739-724&p=f&viewport=475%2C25%2C0.07&t=nsnY7BQNolE7W5xw-1&scaling=min-zoom&content-scaling=fixed)

## Role

Solo build, in progress. The security model is part of the work: row-level security on every table, a JWT-gated AI proxy, auth tokens in the device keychain, and the model key kept off the device.

## Stack

React Native · Expo · TypeScript · Supabase · Anthropic Claude
